# diceChat 🎲

Discord 슬래시 명령어로 주사위를 굴려주는 봇입니다.
초대 링크 하나로 누구나 자기 서버나 DM에서 쓸 수 있습니다.

## 사용법

```
/roll 1d20
/roll 2d6+3
/roll 3d4-2
/roll 2d6*2+1
```

- `NdM`: M면체 주사위를 N개 굴립니다.
- `*K` (선택): 굴리는 횟수를 K배로 늘립니다.
- `+X` / `-X` (선택): 합계에 보정치를 더하거나 뺍니다.
- 한 번에 최대 100개, 면은 최대 1000까지 굴릴 수 있습니다.
- 형식이 틀리면 안내 메시지가 나타납니다.( 본인에게만 )
